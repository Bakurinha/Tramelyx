# Roadmap — Tramelyx

O roadmap prioriza validação do diferencial antes de escala, colaboração ou monetização.

## v0.1 — Foundation

Objetivo: provar identidade, arquitetura e fluxo básico do produto.

- App shell profissional e responsivo
- Dark/light mode
- Dashboard de projeto
- Story Graph demonstrável
- Canon Engine demonstrável
- Knowledge Graph demonstrável
- Timeline
- Reveals
- Validator inicial
- History local
- Persistência local leve
- Documentação e regras de produto

## v0.2 — Local-first real

Objetivo: permitir criar um projeto utilizável sem backend.

- IndexedDB
- Criar/editar/excluir nós
- Conexões visuais
- Importar/exportar JSON
- Schema versionado e migrações
- Projetos múltiplos
- Autosave
- Busca global
- Backup manual

## v0.3 — Canon Engine

Objetivo: tornar o primeiro diferencial realmente útil.

- Fatos de cânone tipados
- Estados: ideia, provisório, cânone, retcon, descartado
- Vigência temporal
- Referências de origem
- Impact analysis básico
- Alertas de contradição

## v0.4 — Knowledge Graph

Objetivo: modelar quem sabe o quê e quando.

- Conhecimento por personagem/facção/leitor
- Origem do conhecimento
- Momento de aquisição
- Informação falsa/suspeita/confirmação
- Alertas de fala/conhecimento precoce

## v0.5 — State Engine

Objetivo: modelar narrativa interativa.

- Variáveis
- Condições
- Efeitos
- Inventário/flags
- Relações/afinidade
- Estado por rota
- Nós inalcançáveis

## v0.6 — Reveal Engine

Objetivo: controlar mistério e exposição.

- Segredos
- Pistas
- Falsas pistas
- Revelações parciais
- Revelação completa
- Conhecimento do leitor por ponto da obra
- Detector de spoiler precoce

## v0.7 — Narrative Validation

Objetivo: transformar regras narrativas em testes executáveis.

- Regras declarativas
- Assertions de narrativa
- Testes por rota
- Diagnóstico de causalidade
- Relatório de cobertura
- Dead ends
- Referências órfãs

## v0.8 — Narrative Git

Objetivo: histórico semântico, não apenas textual.

- Snapshots
- Diff narrativo
- Impacto por alteração
- Restauração
- Anotações de decisão criativa
- Comparação entre versões do cânone

## v0.9 — Engine integrations

Objetivo: aproximar design e implementação.

- Export JSON estável
- Adaptadores para Godot/Unity/Unreal conforme demanda
- IDs imutáveis
- CLI opcional
- Validação no pipeline

## v1.0 — Colaboração e estabilidade

Somente depois que o fluxo local estiver validado:

- autenticação;
- sincronização;
- compartilhamento;
- permissões;
- comentários;
- colaboração em equipe;
- backups remotos;
- suíte de testes e contratos estáveis.

## Fora do foco inicial

- IA que escreve a história no lugar do autor
- marketplace
- monetização precoce
- rede social
- engine de jogo própria
- edição de vídeo/áudio

Esses itens podem ser reconsiderados apenas se houver demanda real e conexão clara com o núcleo do produto.
